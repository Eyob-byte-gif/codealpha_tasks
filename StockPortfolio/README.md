
# Stock Portfolio Tracker

A command-line Python application developed for the CodeAlpha Python Programming Internship.

## Features

- Add stocks to a portfolio
- Track shares and average purchase prices
- Update current stock prices manually
- Calculate investment value and profit or loss
- Remove stocks from the portfolio
- Save and reload portfolio data using JSON
- Validate numeric input
- Automated tests using unittest

## Requirements

- Python 3

No third-party packages are required.

## Run the Application

```bash
python stock_portfolio.py
```

## Run Tests

```bash
python -m unittest discover -s tests -v
```

## Notes

Stock prices are entered manually. This application does not fetch live market data and is intended for programming practice, not investment advice.
