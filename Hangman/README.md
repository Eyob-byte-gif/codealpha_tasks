Hangman Game

A command-line word-guessing game developed as part of the CodeAlpha Python Programming Internship.

Features

- Random word selection
- Visual Hangman stages
- Input validation
- Detection of repeated guesses
- Six incorrect attempts
- Replay functionality

Run the Game

From the repository root, run:

python Hangman/hangman.py

Run the Tests

python -m unittest discover -s Hangman/tests -v

Technologies

- Python
- Python standard library
- "unittest" for automated testing
